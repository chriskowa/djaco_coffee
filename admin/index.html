Keamanan Login (Database & Bearer Token)

Sistem autentikasi kini menggunakan database MySQL dengan enkripsi Bcrypt dan Bearer Token 256-bit yang aman.

Akun default yang tersedia di database:
• Username: admin (Password: admin123 - Hak akses penuh)
• Username: kasir (Password: kasir123 - Hak akses POS & Pesanan)

Proteksi API Aktif: Setiap endpoint perubahan data produk, order, dan rekap keuangan di-validasi secara ketat oleh server API.

Sinkronisasi Penjualan Lama (Google Spreadsheet)

Impor atau sinkronkan data riwayat transaksi penjualan lama dari sheet Penjualan di Google Sheets ke database MySQL lokal. Data yang sudah pernah dimasukkan tidak akan terduplikasi.

Menyinkronkan semua invoice, item pesanan, dan tanggal transaksi lama.
